Included are three ontologies describing the domains of nonlinear dynamics, structural health monitoring, and verification & validation. The ontologies can be used standalone, but are also linked together through common classes.

# dynamics
The dynamics ontology is an ontology describing the fundamentals of nonlinear structural dynamics, covering data-based and analytical knowledge in the field. It is used, in this case, to describe and compare differential equations (an example using the Duffing equation is included in the ontology).

# SHM
The Structural Health Monitoring (SHM) ontology has been created for both the purposes of knowledge-sharing (providing a knowledge-base of the state-of-the-art in algorithms and methods in SHM) and as a database to store and label the data used to achieve SHM. The ontology is also intended for future use in Population-Based SHM (PMSHM).

# VV
The Verification and Validation (VV) ontology is used to describe the processes of verification and validation, and to label work related to these processes. It is useful, for example, in structural dynamics, for quantifying the confidence of model results for a model that, for example, predicts the structural health of a real-world structure.
